# 从零写一个 AI Coding Agent：s01-s06 通俗讲解

这 6 章是构建一个 AI 编程助手最核心的部分。学完它们，你就知道 Claude Code、Cursor 这类工具底层是怎么跑起来的。

## 整体思路：一个不断叠加功能的循环

所有章节都围绕同一个东西——一个 while 循环：

```
用户提需求 → 模型思考 → 模型想调工具 → 执行工具 → 结果喂回模型 → 继续下一轮
```

每一章往这个循环里多加一个机制，循环本身的结构不变。

## 六章关系图

```
s01  让模型"动手"
  │  一个 bash 工具 + 一个 while 循环 = 最小的 agent
  │
  ├─→ s02  让模型"手脚更灵活"
  │    从 1 个工具扩展到 4 个（读文件/写文件/编辑/bash）
  │    关键思路：加工具就是加 handler，循环不用改
  │
  ├─→ s03  让模型"别跑偏"
  │    加一个 todo 工具，把当前要做的事写出来
  │    计划是活的，做完一步就更新，长时间不更新系统会提醒
  │
  ├─→ s04  让模型"分工协作"
  │    父 agent 派子 agent 去做局部任务
  │    子 agent 用干净的上下文干活，只返回结果，不污染主对话
  │
  ├─→ s05  让模型"知道什么时候该查什么"
  │    把领域知识（代码规范、提交流程等）拆成技能包
  │    先告诉模型"有哪些技能可用"，用到的时候再加载完整内容
  │
  └─→ s06  让模型"持续工作不爆内存"
         大工具结果先存盘，旧的替换为占位符，太长时让模型自己写摘要
         目标：保住"继续工作所需的关键信息"，而不是删历史
```

## 适合谁看

- 你有 Python 基础，用过 LLM API（比如 Anthropic 的 SDK）
- 你想知道 AI 编程工具内部是怎么工作的
- 你不想看那种"全是术语、不说人话"的教程

## 不适合谁看

- 你完全没写过代码——这篇假设你至少能用 Python 调用 LLM API
- 你想学怎么训练模型——这 6 章教的是怎么给模型造"载具"，不是造模型本身

## 怎么读

按顺序从 s01 读到 s06。每一章只新增一个机制，跳着读会漏掉依赖关系。

每章的结构都一样：**先讲"为什么要做这个"→ 再讲"怎么做"→ 最后讲"容易踩什么坑"**。
