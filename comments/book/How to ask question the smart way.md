省流：虽然大部分是有关电子技术方面的建议和问题，但是除去这些技术层面的东西，剩下的仍然有助于我们（在社区，论坛中）更高效的提出和解决问题。

- 提问之前：
    1. 尝试在网上搜索答案（推荐google）
    2. 尝试阅读手册，FAQ
    3. 尝试自己检查
    4. 向身边的朋友打听
- 提问时：
    1. 谨慎选择提问的场合（stack exchange>网页论坛>内核邮件列表）
    2. 使用有意义且描述明确的标题
        - 不要太长
        - **目标-差异式**描述
    3. 使问题容易回复
        - 使用正确的语句（否则进行声明。eg.声明英语为second language）
        - 方便对方进行操作回复
        - 使用易于读取的文件格式发送问题（eg.尽量不要发一个需要下载的word文档）
        - 精确描述，言之有物（描述问题症状而非猜测）![[IMG_0148.jpeg]]
        - 不要傲慢，也别低声下气，那不能代替你的功课
        - 去掉无意义提问句（eg有人能帮我吗？）
        - 礼多人不怪
        - 问题解决后，加个补充说明
- 解读答案
    1. RTFM&STFM
    2. 即便还是搞不懂，也应该表现出自己已经从中学到了什么
    3. 无礼的回答：沉住气，看看他是不是说对了，一针见血比模糊礼貌更好
    4. 真的被攻击了：熬过去，这很正常
