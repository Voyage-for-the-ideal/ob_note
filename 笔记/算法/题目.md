### 最小堆实现k个有序数组合并
每次将所有数组的头放入最小堆中，取出最小堆的元素，如果该元素在原数组中还有next，则将其放入，重复上述操作。

优点：额外空间只需要O(k)

### leetcode 49 字符串分组
```c++
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
	    unordered_map<string,vector<string>> mp;
	    
	    for(string& s: strs){//&表示直接取用string中的元素，如果不加就是复制其中元素使用
		    string key=s;
		    sort(key.begin(),key.end());
		    mp[key].push_back(s);
	    }
	    
	    vector<vector<string>> res;
	    for (auto & a : mp){//auto自动根据后面的变量判断类型
		    result.push_back(a.second);
	    }
	    return result;
    }
```
