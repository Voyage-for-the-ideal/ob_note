## 1. 概述

本程序实现了一个通用的线性规划求解器，采用**单纯形法（Simplex Method）**求解如下标准形式的最小化问题：
$$
\begin{aligned}
\min z &= c^T x \\
\text{s.t.}\quad A x &= b \\
x &\ge 0
\end{aligned}
$$

程序支持输入不等式约束（$Ax≤b$）和等式约束（$Ax=b$），能够自动处理转换标准型、去除冗余约束、通过大M法寻找初始基，并使用Bland规则避免循环。

## 2. 模块化设计与流程

程序核心类为 `SimplexSolver`，其主求解函数 `solve()` 按顺序调用四个主要模块：
```python
def solve(self):
    try:
        # 模块0：转换标准形式
        self._module0_to_standard_form()
        
        # 模块1：检查秩并去重
        if not self._module1_check_rank_and_remove_redundancy(): return
        
        # 模块2：初始化可行基解 (大M法)
        self._module2_initialize_basis_big_m()
        
        # 模块3：单纯形法迭代
        self._module3_simplex_iterations()
        
        # 提取结果
        self._extract_solution()
    except Exception as e:
        self.status = f"Error: {str(e)}"
```

### 模块 0：转换标准形式 
> 将用户输入的不等式约束转化为等式约束，并确保右端项$b≥0$。

**流程**：
1. **处理不等式**：对于 $A_{ub}x≤b_{ub}$​，引入松弛变量$s≥0$，转化为 $A_{ub}x+Is=b_{ub}$。松弛变量在目标函数中的系数为 0。
2. **合并约束**：将处理后的不等式约束矩阵与原有的等式约束矩阵 $A_{eq}$​ 合并，形成最终的系数矩阵 A。
3. **处理负右端项**：线性规划标准型要求 $b≥0$。遍历 b 向量，若发现$b_i<0$，则将该行约束两边同时乘以 -1。

### 模块 1：检查满秩与去重 
> 确保约束矩阵 $A$ 是行满秩的，移除线性相关的冗余约束，并检测显式的无解情况。

**流程**：
1. **矛盾检测**：如果存在某一行系数全为 0 但对应 $b$ 不为 0，标记为 `Infeasible`
2. **秩检查与行筛选**：
    - 计算矩阵的秩。如果$rank(A)<m$，说明存在冗余。
    - 采用增量法筛选线性无关组：逐行添加约束，如果加入某行后矩阵的秩没有增加，则说明该行是冗余的，将其移除。

### 模块 2：初始化可行基解 - 大M法
> 寻找一个初始的基本可行解。对于无法直接找到单位向量列的约束行，引入人工变量。

**流程**：
1. **寻找现成基变量**：扫描矩阵$A$的每一列，寻找是否已经存在单位向量（如松弛变量）。
2. **添加人工变量**：对于还未找到基变量的行 $i$，构造人工变量 $x_a​$，使得该列为 $e_i​$。
3. **大M惩罚**：在目标函数中给人工变量赋予极大的正系数$M$，迫使在迭代过程中优先将人工变量移除基或变为 0。


### 模块 3：单纯形法迭代
> 执行单纯形算法的主循环，实现基变换，直到找到最优解或判定无界。

**流程**：
1. **计算检验数 (Reduced Costs)**：  
    计算 $σ=c−c_{BA}$。其中 $c_B$​ 是当前基变量的价值系数。
2. **最优性检验**：  
    对于最小化问题，如果所有检验数 $σ_j≥0$，则当前解为最优解，停止迭代。
3. **入基变量选择 (Entering Variable)**：  
    使用 **Bland规则**：选择 $σ_j<0$中下标 $j$ 最小的变量入基。这防止了退化情况下的死循环。
4. **出基变量选择 (Leaving Variable)**：  
    进行**最小比率测试**：计算 $θ=min⁡\{b_i/A_{ij}∣A_{ij}>0\}$。  
    如果所有 $A_{ij}≤0$，说明问题**无界 (Unbounded)**。  
    若有多个行使得比率最小，使用 **Bland规则**：选择基变量下标最小的那一行。
5. **旋转变换 (Pivot)**：  
    使用高斯消元法将入基变量对应的列化为单位向量，同时更新 $b$ 和其余各列，实现基的切换。

程序包含 `benchmark.py`，用于生成不同类型的测试数据：
- **Fundamental Cases**：随机生成 $A,b,c$，构造可行且有界、无可行解、无界、含冗余约束四种情况。
- **Stress Test**：主要关注有界最优解情况下的性能。

![D:\code\operation_research\Simplex Method\simplex_benchmark.png](file:///d%3A/code/operation_research/Simplex%20Method/simplex_benchmark.png)

通过对不同规模（变量数 $n$ 从 10 到 200）的随机问题进行测试：随着变量增加，求解时间呈现非线性增长。
- **数据**：当 $n=50$ 时耗时约 2ms，当 $n=100$ 时耗时约 17ms，当 $n=200$ 时耗时约 150ms。
- **结论**：实测增长趋势接近 $O(n^3)$，这符合单纯形法在一般情况下的经验平均复杂度（迭代次数 $O(n)$× 单次迭代 $O(n^2)$）。(迭代次数与约束数量有关 $O(m)$ ，在这里约束数量$m=0.6n$）
