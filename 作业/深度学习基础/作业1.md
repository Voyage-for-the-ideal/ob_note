### 1. 举例一个能够应用机器学习解决问题的例子，要和科大相关
预测科大学生在图书馆的“座位使用时长“。我们可以构建一个机器学习模型，根据学生刷卡进入图书馆的时间、历史借阅记录、当前学期等因素，来预测该学生这次会在图书馆待多久。

### 2. 梳理在这个机器学习问题中应该考虑哪些特征
| 特征类别     | 具体特征        | 说明                                |
| -------- | ----------- | --------------------------------- |
| **时间特征** | 进入时间（小时/分钟） | 早晨来的同学往往比傍晚来的同学坐得更久               |
|          | 星期几         | 周末和平时的学习时长分布不同                    |
|          | 是否考试周       | 考试周学习时长普遍更长（可以从校历生成）              |
| **用户画像** | 年级          | 大一新生可能更坐得住，大四考研党时长长，大二大三波动大       |
|          | 学院/专业       | 不同专业的课业压力和阅读任务不同                  |
|          | 历史平均停留时长    | 该同学过去一周/一个月的平均学习时长                |
| **历史行为** | 上次借阅书籍数量    | 借书多可能意味着要写论文或做项目，需要长时间阅读          |
|          | 过去一周入馆次数    | 高频入馆者可能是有固定学习习惯的人                 |
| **环境特征** | 当前图书馆总空座数   | 座位紧张时，学生可能会因为心理压力而提早离开（或者相反，不敢离开） |
|          | 天气（晴/雨）     | 雨天学生可能更愿意留在室内，延长学习时间              |

### 3. 阐述为什么在这些特征上使用深度学习模型会比线性回归有优势
线性回归假设特征与目标变量（停留时长）之间存在**线性关系**，并且要求特征之间**相互独立**（低多重共线性）。

然而在这个场景中，存在以下几个复杂因素，使得深度学习（如简单的多层感知机 MLP）更有优势：

**1. 特征之间存在复杂的非线性交互作用**
- 例如，**“考试周”** 和 **“历史平均时长”** 这两个特征的组合效应并不是简单的相加。在非考试周，历史时长长的同学可能今天只是来还书（短时）；但在考试周，这些同学可能会超长待机。深度学习可以通过激活函数（如ReLU）自动学习这种 `考试周 × 历史时长` 的高阶交互。

**2. 特征的尺度差异大，且分布复杂**
- “进入时间”是周期性变量（23点和0点很近，但数值差23）。深度学习可以通过嵌入层（Embedding）将时间转换为向量，或结合正弦余弦变换来处理周期性。
- 线性回归对异常值敏感（比如某天图书馆停电导致所有人立刻离开），而深度学习模型通过多层非线性变换，对噪声的鲁棒性通常更强。

**3. 能够自动进行特征提取**
- 原始特征可能较稀疏（如“学院”有几十个类别）。线性回归需要做独热编码，会导致维度灾难；而深度学习可以通过嵌入层将高维稀疏特征映射到低维稠密向量，自动学习学院之间的相似性（比如“物理学院”和“少年班学院”可能有相似的学习时长模式）。
