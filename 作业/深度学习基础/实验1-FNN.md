## 一、数据集与预处理

### 数据集划分
Diabetes 数据集包含 442 个样本，每个样本包含 10 个数值特征，预测目标为疾病进展指标（连续值），属于典型回归任务。

- 测试集划分：按 5:1 将原始数据划分为训练验证临时集与测试集。
- 验证集划分：对临时集按 4:1 划分训练集与验证集。

###  张量化与批加载
将数据转换为 `torch.float32`，并构建 DataLoader：
- batch size = 32
- 训练集开启 shuffle
- 验证/测试集不打乱

## 二、模型与训练方法
### 1. 模型结构
使用可配置的多层感知机（FNN）：
- 输入层维度：10
- 隐藏层：按实验配置动态构建（如 [32]、[64,32]、[128,64,32]）
- 输出层维度：1（回归）
### 2. 训练配置
- 损失函数：MSELoss
- 优化器：Adam
- 训练轮数：200 epoch
- 早停策略：未使用显式早停，但每轮记录验证集损失并保存验证最优参数，训练结束后回载最佳权重。
### 3. 评估指标
- 验证集最优 MSE（训练过程中最小验证损失）
- 测试集 MSE（最终泛化性能）

## 三、实验结果

### 实验1：网络深度影响
设置：激活函数 ReLU，学习率 0.01。实验结果如下：

![[Pasted image 20260315233805.png]]

| 网络结构                         |       最优验证MSE |        测试集MSE |
| ---------------------------- | ------------: | ------------: |
| Shallow (1 Layer, [32])      |     2461.3230 |     3159.3230 |
| Medium (2 Layers, [64,32])   | **2344.7392** |     3060.5125 |
| Deep (3 Layers, [128,64,32]) |     2364.2594 | **3050.4193** |

结果分析：
1. 两层与三层网络相较单层网络测试误差更低，说明适度加深网络可提升表达能力。
2. 三层网络测试 MSE 最低（3050.42），但优势相对两层网络较小。
3. 深度继续增加未必线性提升，任务规模较小（442 样本）时过深网络收益有限。

### 实验2：学习率影响
设置：固定网络 [64,32]，激活函数 ReLU。实验结果如下：
![[Pasted image 20260315233914.png]]

|    学习率 |       最优验证MSE |        测试集MSE |
| -----: | ------------: | ------------: |
|    0.1 | **2337.0873** |     3101.8769 |
|   0.01 |     2354.9455 | **3007.1806** |
|  0.001 |     2656.4184 |     3184.1530 |
| 0.0001 |    21455.4211 |    19126.1732 |

结果分析：
1. 学习率过小（0.0001）明显欠拟合，200 轮内几乎无法有效收敛。
2. 0.001 收敛过慢，最终性能不如 0.01。
3. 0.1 和 0.01 均可快速下降；其中 0.01 测试集 MSE 最优（3007.18），表现出更好的稳定性与泛化能力。

### 实验3：激活函数影响
设置：固定网络 [64,32]，学习率 0.01。实验结果如下：
![[Pasted image 20260315234002.png]]

| 激活函数      |       最优验证MSE |        测试集MSE |
| --------- | ------------: | ------------: |
| Sigmoid   |     2682.5164 | **2910.2867** |
| Tanh      |     3014.3588 |     3356.5476 |
| ReLU      |     2370.0728 |     3090.4898 |
| LeakyReLU |     2354.8812 |     3010.1451 |
| Swish     | **2324.8778** |     3142.7421 |

结果分析：
1. 本次实验中 Sigmoid 在测试集取得最低 MSE（2910.29），但其验证最优值并非最低，说明其泛化表现与训练轨迹存在一定波动。
2. LeakyReLU 与 ReLU 在验证集表现稳定，且测试结果较好（3010.15 与 3090.49）。
3. Tanh 表现最弱，可能与当前学习率和网络配置匹配度较低有关。
4. 激活函数效果受初始化、学习率、训练轮次和随机种子影响较大，结论应基于多次重复实验更稳妥。

## 六、综合结论
1. 对于本任务，适度增加网络深度（2~3层）能优于单层模型，但继续加深收益有限。
2. 学习率是最关键超参数之一，0.01 在本实验中取得最佳综合效果；过小学习率会显著拖慢收敛并导致高误差。
3. 激活函数并无绝对最优，需结合任务与超参数联合调优；在本次设置下 Sigmoid 测试结果最好，LeakyReLU 与 ReLU 更稳定。

如果要使用该数据集进行训练，应设置\[64,32\]隐藏层，学习率0.01，激活函数Sigmoid，在目标设置为MSE时可以达到最好效果。
