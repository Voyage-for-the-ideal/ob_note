## 算法原理

### 度中心性 (Degree Centrality)
衡量节点直接邻居的数量。反映了节点的局部连通性。
$$C_D(v) = \frac{deg(v)}{n-1}$$

```python
def degree_centrality(G: Graph) -> dict[int, float]:
    """
    度中心性：C_D(v) = deg(v) / (n - 1)
    """
    nodes = list(G.nodes)
    n = len(nodes)
    if n <= 1:
        return {v: 0.0 for v in nodes}
    return {v: G.degree(v) / (n - 1) for v in nodes}

```

### 接近中心性 (Closeness Centrality)
衡量节点到网络中所有其他节点的平均最短路径距离之倒数。得分越高，信息从该节点出发到达全网的速度越快。
$$C_C(v) = \frac{n-1}{\sum_{u \neq v} d(v, u)}$$

```python
def closeness_centrality(G: Graph) -> dict[int, float]:
    """
    接近中心性：C_C(v) = (n - 1) / Σ_{u≠v} d(v, u)
    """
    nodes = list(G.nodes)
    n = len(nodes)
    centrality = {}
    for v in nodes:
        dist, _, _, _ = bfs_shortest_paths(G, v)
        sum_dist = sum(dist.values())
        if sum_dist > 0 and n > 1:
            # 这里的公式通常对连通图有效，非连通图可能需要修正
            # 按照作业提示：(n - 1) / sum_dist
            centrality[v] = (n - 1) / sum_dist
        else:
            centrality[v] = 0.0
    return centrality

```

### 中介中心性 (Betweenness Centrality)
衡量节点作为“桥梁”控制网络中信息流动的能力。本实验采用 **Brandes 算法**，通过 BFS 统计节点在所有最短路径中出现的频率。
$$C_B(v) = \sum_{s \neq v \neq t} \frac{\sigma_{st}(v)}{\sigma_{st}}$$

```python
def betweenness_centrality(G: Graph) -> dict[int, float]:
    """
    中介中心性（Brandes 算法）：
      C_B(v) = Σ_{s≠v≠t} σ_st(v) / σ_st
    """
    nodes = list(G.nodes)
    n = len(nodes)
    bc = {v: 0.0 for v in nodes}
    
    for s in nodes:
        dist, sigma, pred, order = bfs_shortest_paths(G, s)
        delta = {v: 0.0 for v in nodes}
        # 反向累积
        for w in reversed(order):
            for v in pred[w]:
                delta[v] += (sigma[v] / sigma[w]) * (1.0 + delta[w])
            if w != s:
                bc[w] += delta[w]
                
    # 归一化：无向图除以 (n-1)(n-2) / 2，
    # 但作业提示中写的是 (n-1)(n-2)，这里按照提示或常用标准
    # 对于无向图，通常路径 s->t 和 t->s 是同一条，所以最后要除以 2
    norm = (n - 1) * (n - 2) if n > 2 else 1.0
    for v in bc:
        bc[v] /= norm
        
    return bc

```

### PageRank 算法
基于链接传递的重要性评估。不仅考虑邻居数量，还考虑邻居本身的重要性。采用幂迭代法求解，阻尼系数 $\alpha=0.85$。

```python
def pagerank(
    G: Graph, alpha: float = 0.85, max_iter: int = 100, tol: float = 1e-6
) -> dict[int, float]:
    """
    PageRank：PR(v) = (1-α)/n + α × Σ_{u→v} PR(u) / deg(u)
    """
    nodes = list(G.nodes)
    n = len(nodes)
    if n == 0:
        return {}
    
    # 初始化
    pr = {v: 1.0 / n for v in nodes}
    
    for _ in range(max_iter):
        new_pr = {}
        # 悬挂节点处理（没有邻居的节点，PR平分给所有人）
        dangling_sum = sum(pr[v] for v in nodes if G.degree(v) == 0)
        for v in nodes:
            # 基础分
            rank_sum = (1.0 - alpha) / n + alpha * (dangling_sum / n)
            # 邻居分
            for u in G.neighbors(v):
                rank_sum += alpha * (pr[u] / G.degree(u))
            new_pr[v] = rank_sum
        # 检查收敛
        diff = sum(abs(new_pr[v] - pr[v]) for v in nodes)
        pr = new_pr
        if diff < tol:
            break
            
    return pr
```

## 实验实现

### 图结构存储
使用 **邻接表 (`dict[int, set[int]]`)** 存储无向图。该结构在处理稀疏社交网络时具有极高的空间利用率，且查询邻居的时间复杂度为 $O(1)$。
```python
class Graph:
    def __init__(self):
        self.nodes = set()
        # 使用邻接表存储图：dict[int, set[int]]
        self._adj = {}
        self._num_edges = 0

    def add_node(self, node_id: int):
        """添加节点。"""
        if node_id not in self.nodes:
            self.nodes.add(node_id)
            self._adj[node_id] = set()

    def add_edge(self, u: int, v: int):
        """添加无向边 (u, v)。"""
        self.add_node(u)
        self.add_node(v)
        if v not in self._adj[u]:
            self._adj[u].add(v)
            self._adj[v].add(u)
            self._num_edges += 1

    def neighbors(self, node_id: int):
        """
        返回 node_id 的邻居
        """
        return self._adj.get(node_id, set())

    def degree(self, node_id: int) -> int:
        """返回 node_id 的度数。"""
        return len(self._adj.get(node_id, []))

    def number_of_edges(self) -> int:
        """返回图中边的数量（每条无向边只计一次）。"""
        return self._num_edges

```
### 关键代码实现
*   **BFS 工具函数**：一次性返回距离 (`dist`)、路径数 (`sigma`) 和前驱节点 (`pred`)，为多种算法提供底层支撑。

```python
def bfs_shortest_paths(
    G: Graph, source: int
) -> tuple[dict[int, int], dict[int, int], dict[int, list[int]], list[int]]:
    dist = {source: 0}
    sigma: dict[int, int] = {v: 0 for v in G.nodes}
    sigma[source] = 1
    pred: dict[int, list[int]] = {v: [] for v in G.nodes}
    order: list[int] = []
    
    queue = deque([source])
    visited = {source}
    
    while queue:
        u = queue.popleft()
        order.append(u)
        for v in G.neighbors(u):
            if v not in dist:
                dist[v] = dist[u] + 1
                queue.append(v)
            if dist[v] == dist[u] + 1:
                sigma[v] += sigma[u]
                pred[v].append(u)

    return dist, sigma, pred, order
```

*   **SIR 模拟逻辑**：实现 `S(易感)->I(感染)->R(恢复)` 状态机，模拟信息在网络中的随机扩散。
```python
def sir_simulation(
    G: Graph,
    seeds: list[int],
    beta: float = 0.3,
    gamma: float = 0.1,
    max_steps: int = 5,#表示最大传播步数
) -> list[dict[int, str]]:
    """
    SIR 传播模型。
    """
    nodes = list(G.nodes)
    # 初始化状态
    state = {v: 'S' for v in nodes}
    for s in seeds:
        state[s] = 'I'
    #S: 易感者，I: 感染者，R: 康复者
    history = [state.copy()]
    
    for _ in range(max_steps):
        new_state = state.copy()
        infectious_nodes = [v for v, s in state.items() if s == 'I']
        
        if not infectious_nodes:
            break 
              
        for v in infectious_nodes:
            # 尝试感染邻居
            for u in G.neighbors(v):
                if state[u] == 'S':
                    if random.random() < beta:
                        new_state[u] = 'I'
            # 尝试恢复
            if random.random() < gamma:
                new_state[v] = 'R'
        
        state = new_state
        history.append(state.copy())
    return history
```
