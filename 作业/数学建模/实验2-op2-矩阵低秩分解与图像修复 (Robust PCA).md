## 0. 实验结果综述

本次实验成功实现并验证了基于 **Inexact ALM (不精确增广拉格朗日乘子法)** 的 RPCA 算法框架。实验结果表明：
1. **在图像修复方面**：我们实现了传统的 **RPCA** 以及进阶的 **Patch-based SLRT (基于图块的低秩纹理修复)** 两种处理方法。较好地剥离了图像中随机遮挡与污迹噪声。在引入块匹配特征后，系统对存在连续宽大断层的结构也具有了一定的修补能力。
2. **在视频处理方面**：通过时间轴上的列向量堆叠，算法能够对固定视角监控视频进行有效的 **“动静分离”**。从含有行人、车辆等移动干扰的视频流中，较为完整地提取出了静态背景（低秩项）以及运动前景（稀疏项）。

## 1. 实验背景与动机

本次实验的主要目的是探究**鲁棒主成分分析（Robust PCA）** 在图像处理及数据修复中的理论基础与实际应用效果。传统的 PCA 基于 L2 范数，在面对稀疏但幅度较高的噪声（如大块遮挡、强烈的椒盐噪声）时极其脆弱。

而 RPCA 的主要思想是基于观测矩阵 $A$，尝试将其天然解耦为：

$$ A = L + S $$

其中 $L$ 为真实背景/无损细节的低秩矩阵，而 $S$ 为异常值、文本、污点或前景移动物体等稀疏矩阵。

  
## 2. 核心数学原理解读

### 2.1 优化模型构建

在完全理想的情况下，RPCA 的优化目标是最小化矩阵 $L$ 的秩以及矩阵 $S$ 的非零元素个数（L0 范数）：

$$ \min_{L,S} \ \mathrm{rank}(L) + \lambda \|S\|_0 \quad \text{s.t.} \ A = L + S $$

然而这种秩最小化与 L0 优化都是 NP-hard 问题。在数学上，我们可以通过**核范数（Nuclear Norm, $\|\cdot\|_*$）** 来凸松弛 $\mathrm{rank}(\cdot)$，通过 **L1 范数（$\|\cdot\|_1$）** 来凸松弛 $\|\cdot\|_0$。

最终可解的凸优化基准问题形式化为（PCP模型）：

$$ \min_{L,S} \ \|L\|_* + \lambda \|S\|_1 \quad \text{s.t.} \ A = L + S $$

其中 $\lambda$ 用于权衡“低秩性”与“稀疏性”之间的比例，本实验中使用$\frac{1}{\sqrt{max\{m,n\}}}$。

  
### 2.2 Inexact ALM 求解方法

实验采用**不精确增广拉格朗日乘子法 (Inexact ALM)** 进行高效求解。定义增广拉格朗日函数为：

$$ \mathcal{L}(L, S, Y, \mu) = \|L\|_* + \lambda \|S\|_1 + \langle Y, A - L - S \rangle + \frac{\mu}{2} \|A - L - S\|_F^2 $$

通过交替固定某一变量更新另一变量（ADMM 思路）直至残差收敛。每次更新 $L$ 需要进行奇异值分解 (SVD) 并做软阈值截断，更新 $S$ 只需要做逐元素的软阈值收缩（Soft Thresholding）。

  
## 3. 算法伪代码实现 (Pseudocode)

```
Algorithm: Inexact ALM for RPCA (A = L + S)
Input: 观测矩阵 A, 惩罚参数 λ
Initialize:
    L = 0, S = 0, Y = 0
    μ > 0, ρ > 1 (加速收敛)
    tol = 1e-7
  
While ||A - L - S||_F / ||A||_F > tol do:
    1. Update L (低秩更新):
       (U, Σ, V^T) = SVD(A - S + (1/μ) * Y)
       L = U * SoftThreshold(Σ, 1/μ) * V^T
       
    2. Update S (稀疏更新):
       S = SoftThreshold(A - L + (1/μ) * Y, λ/μ)

    3. Update Y (拉格朗日乘子更新):
       Y = Y + μ * (A - L - S)

    4. Update μ (步长自适应):
       μ = ρ * μ

End While

  
Output: L (低秩背景), S (稀疏前景或噪点)
```

## 5. 监控视频背景分离效果解读 (Video RPCA)

相对于图像处理，低秩矩阵分解用于视频的前景/背景分离才是其原始理论的最佳落脚点之一。我们分别采用了**街景和火焰燃烧的短视频**，并尝试从视频中提取静态的背景。


### 5.1 矩阵构造原理：时间轴上的列向量堆叠

在视频背景分离中，观测矩阵 $A$ 的构造方式与单张图像截然不同。其核心思想是将 **“空间相邻”** 转化为 **“时间相关”**：

1. **向量化处理 (Vectorization)**：将视频的每一帧转换为一维稠密列向量。若单帧分辨率为 $W \times H$，且包含 $C$ 个色彩通道，则每帧对应的向量维度为 $D = W \times H \times C$。
2. **时空同步堆叠 (Temporal Stacking)**：若视频共有 $N$ 帧，我们将这 $N$ 个列向量按时间顺序并排排列，构成一个大张量矩阵 $A_{\text{video}} \in \mathbb{R}^{D \times N}$：
   $$ A_{\text{video}} = \left[ \mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3, \dots, \mathbf{v}_N \right] $$
3. **物理意义映射**：
   * **行向量 (Row Vector)**：代表了视频中某一个特定像素坐标 $(x, y)$ 在随时间变化（$t_1, t_2, \dots, t_N$）下的亮度/颜色变化轨迹。
   * **低秩性来源**：由于监控摄像头固定，背景像素在时间维度上表现出极强的平稳性（Stationarity），即使有轻微的光照波动或相机抖动，这 $N$ 列之间依然存在极高的相关性，从而表现为 **低秩矩阵 $L$**。
   * **稀疏性来源**：移动物体（如行人、车辆）仅在极少数的时间点（即矩阵中极少数的列）出现在特定的像素位置，这种在时空域上的局部跳变与背景高度不相关，构成了 **稀疏矩阵 $S$**。

* **低秩场景 ($L$)的物理映射**：视频拍摄期间，监控摄像头是基本静止的（例如固定面对高速公路或扶梯），这意味着虽然时间流逝（矩阵列数增加），但大量的背景像素**随时间保持高度一致**，因此由静止背景组成的矩阵的“秩”是极低的。我们在结果图中能看到所有移动的人物被掏空，完美呈现了一条干干净净的“鬼影空街”。

## 6. 交互式图形用户界面 (GUI) 的实现

为了方便测试和比对各种算法在不同参数及干扰条件下的效果，本次实验利用 `tkinter` 搭建了一个基础的图形用户界面。

### 6.1 两种分解算法的对比实现
在界面中提供了两种算法的下拉切换：
1. **传统 RPCA**：按照 Inexact ALM 原理对整张图像矩阵（RGB 图像则逐通道并行分解）进行低秩和稀疏运算。该方法实现简单，但受限于自然图像高频细节较多（本身秩较高），容易将部分清晰背景误判为噪声。
2. **基于图像块的分解 (Patch-based SLRT)**：针对自然图像全局非低秩的问题，将图像切割为小图块（如 $16 \times 16$）并展平为列向量。借用局部纹理的相似性构建具有更强低秩属性的新张量后执行 RPCA。此方法在应对较大面积的突发噪声时表现相对更好。

### 6.2 GUI 主要功能
* **RGB 通道兼容**：支持读取灰度图与 RGB 三通道全彩图，内部进行了对应的数据通道解耦和循环处理。
* **超参数调节**：提供了 $\lambda$ 参数的基础预设选取。用户可在理论建议值 $1/\max(m,n)$、经验放宽惩罚值 $1/\sqrt{\max(m,n)}$ 以及自定义数值之间切换。在切块处理模式下，程序会自动依据拉平后的新矩阵维度动态重算 $\lambda$ 基准值。
* **“死块”干扰模拟**：在控制区添加了“添加死块”功能，借以在原图打上黑带以模拟真实的传感器数据丢失。这一功能用于直观地区分 RPCA（单纯的 2D 信息填补）与由局部块堆叠重组的 SLRT 算法在应对大面积像素丢失时的效果差异。
* **异步计算机制**：考虑到大矩阵的 SVD 耗时长，GUI 运用 `threading.Thread` 将大循环算法推入后台运算队列，防止由主线程阻塞引起的界面无响应，并通过进度条标识运行状态。

## 7. 实验总结与不足之处

本次实验尽管利用代码实现并观察到了矩阵分解在分离稀疏噪声时的奇妙特性，但其实际效果和工程架构层面上仍存在诸多局限与遗憾：

1. **计算复杂度与算力瓶颈**：SVD 分解的时间复杂度极高 ($\mathcal{O}(n^3)$)。对于高分辨率图片以及长视频序列生成的巨大展开矩阵，即使采用了 Inexact ALM 极大地减少了收敛轮次，其实际算力与内存开销依然极高。
2. **无法找到分块算法 (SLRT)与传统鲁棒PCA的区别**“：尽管尝试了很多张图片与不同的噪声处理，但最终两种方法得到的处理图片区别不大。
3. **超参数的通用性极差**：实验发现，无论是图像修复还是视频分离，其效果都极度依赖 $\lambda$ 的选取，但目前仅有基础的经验公式（$\sim 1/\sqrt{\max(m,n)}$）。缺乏一种能够动态探测图像信噪比、遮挡密度并自适应选取最优化 $\lambda$ 的调节机制。
4. **被迫放弃的空间几何形变纠正 (TILT)**：虽然实验中尝试编写并调试了 TILT 算法以对抗带有拍摄视角的斜拍碑文或条形码，但完整的 TILT 需要解算具有 $8$ 个自由度的透视单应矩阵 (Homography/Perspective Transform)，并通过复杂的 Jacobian 矩阵进行泰勒展开近似。受限于个人能力与时间跨度，目前的基准实现中只完成了简单的二维平面 $[-45^\circ, 45^\circ]$ 旋转搜索，彻底丧失了处理真实物理世界梯形畸变的能力，使得该路线的收敛效果近乎不可控，最终只能将其从实验报告的核心展示板块中遗憾移除。
