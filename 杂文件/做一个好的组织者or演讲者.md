# 组织者
1. 开一个有效的会议
    1. 如果自己是组织者，那么就要以身作则，关注会议内容
    2. 开会前一定要把事情讲清楚，必要时让他们可以提问
    3. 开会时关上门，提前调试音量等设备问题（如果涉及视频）
2. 设置截止时间
3. 不要朝令夕改
4. 告诉队员你想要什么，而不是要他们做什么（但是基本的操作要知道怎么做）
5. 营造一个良好，友善的氛围，而非只是做工作。你的队员是人，不是机器人
6. 一次性把会议要求，细节等说完，还有工作安排
    1. 时间段，地点
    2. 参会报名人数，附带的报名表/签到表
    3. 活动流程，项目征集
    4. 报销，新闻稿，主持人，表格打印，奖品准备
7. **一定要有人牵头督促**
# 演讲者
1. 引导观众提问（尤其是最后一张ppt）
2. 讲话要不疾不徐（和第三点意义相像）
3. ppt字不必太多，它只是起辅助作用
4. 图胜于言
5. 一定要事先考虑受众的接受程度，不要一个人自娱自乐
